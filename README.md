# Mossberg Patriot .308 Winchester

Magyar nyelvű, reszponzív típusbemutató, valós termékfotókkal. Bemutatott kivitelek: Patriot Walnut .308, Patriot Walnut Vortex Scoped Combo .308 és Patriot Predator .308 FDE.

## Felépítés és megnyitás

A JavaScript az index.html fájl <script> elemében található, és a teljes látható oldalt létrehozza. A style.css a megjelenést, az assets mappa a termékfotókat tartalmazza. A ZIP kicsomagolása után az index.html böngészőből megnyitható; a CSS és az assets mappa maradjon mellette.

Tusanyag szerinti szűrés, három részletes adatlap, anyagismertető, fogalomtár és mobilmenü. A képek a bemutatott változatok megjelenését szemléltetik; a fotókon látható felszereltség eltérhet más kivitelektől. Független ismeretterjesztő oldal.

## GitHub beadás

Hozz létre egy Public tárolót, és töltsd fel az index.html, style.css, README.md fájlokat, valamint az assets mappát a tartalmával együtt. A tároló nyilvános linkjét add be. GitHub Pages esetén a main ág gyökérmappájából publikáld.
